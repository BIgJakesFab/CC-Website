# Crafted Creations website

Open `index.html` to preview the homepage. The video players and web fonts need an internet connection.

| To change | Edit |
| --- | --- |
| Homepage text, navigation, or project cards | `index.html` |
| Saw blade photos and Shorts | `saw-blades.html` |
| Wood project photos and Shorts | `wood-projects.html` |
| Colors, fonts, and spacing | `assets/site.css` |
| Images | `assets/` |

To replace a photo, upload a new image with the same filename and format, or update the image path in the page. When replacing a YouTube Short, update both the player URL and the Watch on YouTube link.

Preview changes before merging to `main`. GitHub Pages serves the public site from this repository.
